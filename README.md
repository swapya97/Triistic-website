# Triistic Global Website

Official website for **Triistic Global** — outsourced accounting, bookkeeping, AP/AR, FP&A, and controller services for US businesses and CPA firms, led by Chartered Accountants.

## Overview

A responsive, SEO-optimized website built with:
- HTML5 & CSS3
- Bootstrap 5
- Bootstrap Icons & Font Awesome
- jQuery & Owl Carousel
- Google Fonts (Poppins, Roboto)

## Running Locally

To preview the website locally, run a local web server from this directory:

```bash
# Python 3
python -m http.server 8000
```

Then open your browser and navigate to `http://localhost:8000`.
